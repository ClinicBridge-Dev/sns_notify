# 왓츠앱 로컬 수집기 (local-whatsapp) 기획서

## 최근 업데이트 (최신 3개)

### 2026-11-10 — 아직 반영 전 (MVP 범위 변경)
- **[변경] MVP는 "새 메시지 알림"만:** 왓츠앱과 인스타그램(Primary·General)에 새 메시지가 오면 Slack으로 "새로운 알림 N건 / 확인하지 않은 알림 M건"과 마지막 메시지 미리보기를 알려요. 몇 초 사이에 온 것은 한 메시지로 묶어요.
- **[변경] 왓츠앱은 대화 목록만 읽어요:** 대화방을 열지 않아서 안 읽음 뱃지가 사라지지 않아요. ~~대화방을 열어 전체 대화를 저장·번역하는 방식~~은 읽음 처리가 되므로 기본에서 빼고, 설정(`mode: collect`)으로만 켤 수 있게 남겼어요.
- **[추가] 운영 가이드:** 설치, 매일 확인할 것, 하지 말아야 할 것, 문제 해결을 `docs/OPERATIONS.md`에 정리했어요.

### 2026-11-10 — 아직 반영 전
- **[추가] 인스타그램 새 메시지 알림:** Chrome 확장 프로그램이 인스타그램 DM 목록(Primary·General)에서 안 읽은 대화만 확인해 Slack과 대화 화면 상단에 알려요. 대화방은 열지 않아서 읽음 처리가 되지 않아요. 메시지 내용 전체가 아니라 "누가 보냈는지 + 미리보기"까지만 봐요.
- **[변경] WhatsApp 화면 읽기 실기기 확인:** 「WhatsApp 수집기」 앱이 직접 화면을 읽도록 바꾸고, 실제 대화 3개를 읽어 화면에 띄웠어요.

### 2026-11-09 — 아직 반영 전 (코드 1차 완성)
- **[변경] Mac 앱 「WhatsApp 수집기」로 실행:** 메뉴 막대에 아이콘이 있는 앱 하나에만 「손쉬운 사용」 권한을 주면 돼요. 화면 글자는 이 앱이 직접 읽고, 수집 프로그램은 앱에 요청만 해요. 앱이 수집 프로그램을 켜 두고, 꺼지면 다시 켜고, Mac이 잠들지 않게 해요. 터미널에서 명령어를 칠 필요가 없어요.
- **[추가] 저장·번역·Slack 알림·직원용 대화 화면 1차 완성:** 계획서의 1~5단계를 만들었어요. 가짜 대화 데이터로 "저장 → 번역 → 고객 메시지만 Slack 알림 → 화면에 실시간 표시"가 끝까지 도는 것을 확인했어요. 같은 분에 보낸 "네" 두 개도 따로 저장되고, 프로그램을 껐다 켜도 중복 저장·중복 알림이 없어요.
- **[추가] 화면 읽기 실험 도구:** Mac의 「손쉬운 사용」으로 왓츠앱 화면 구조를 기록하는 도구를 만들었어요. 실제 왓츠앱 화면을 읽는 부분은 이 도구로 구조를 확인한 뒤 작성해요. 그 전까지는 아무것도 추측해서 저장하지 않아요.

## 1. 한 줄 소개
상담용 왓츠앱 계정에 오가는 고객·상담사 메시지를 사무실 Mac mini가 화면에서 읽어 모아 두고, 한국어로 번역해 Slack에 알려 주고, 직원이 고객별로 대화 흐름을 볼 수 있게 해 주는 서비스예요.

## 2. 배경과 목표
- 해결하는 문제: 지금은 상담사 휴대폰의 왓츠앱에만 대화가 남아서, 다른 직원이 고객 문의를 바로 알기 어렵고 나중에 맥락을 찾아보기도 어려워요. Meta 공식 API 심사(「CB 왓츠앱」 프로젝트)와 별개로, 심사 없이도 당장 쓸 수 있는 방법이 필요해요.
- 목표(성공했다고 볼 기준): 테스트 고객 번호로 보낸 긴 글·연속 메시지·외국어 메시지가 빠짐없이 저장되고, 외국어는 한국어와 함께 Slack에 뜨고, 직원 화면에서 그 대화가 그대로 보이면 1단계 성공이에요.

## 3. 사용자와 사용 장면
| 사용자 | 주로 하는 일 | 쓰는 화면 |
| --- | --- | --- |
| 고객 | 왓츠앱으로 클리닉 상담 계정에 문의를 보내요 | 고객 휴대폰의 왓츠앱 |
| 상담사 | 휴대폰 왓츠앱으로 답장해요. 답장도 자동으로 저장돼요 | 상담사 휴대폰의 왓츠앱 |
| 직원(6명 내외) | Slack 알림을 받고, 앞뒤 맥락이 궁금하면 대화 화면을 열어 봐요 | Slack 채널, 사무실 PC의 대화 화면 |

## 6. 다른 프로덕트와의 연결
- **CB 왓츠앱**(Meta 공식 API 방식, `cb-whatsapp.vercel.app`)과는 다른 프로덕트예요. 그쪽은 Meta 심사를 통과해야 쓸 수 있고, 이쪽은 심사 없이 Mac mini에 로그인한 왓츠앱 화면을 읽어요. 나중에 심사가 통과되면 이쪽의 "화면 읽기" 부분만 공식 API로 바꿀 수 있게 데이터 구조를 맞춰 둬요.
- Slack 알림 채널은 고객사별로 정해요. 「CB 왓츠앱」과 같은 채널을 쓸지는 아직 정하지 않았어요.

## 7. 운영 원칙·제약
- **읽기만 해요.** 이 서비스는 왓츠앱으로 메시지를 보내지 않고, 직원 화면에도 답장 칸이 없어요. 답장은 지금처럼 상담사 휴대폰으로 해요.
- **원문을 먼저 저장해요.** 번역이 실패해도 고객이 쓴 원문은 이미 저장돼 있어요. 번역문이 원문을 덮어쓰지 않아요.
- **고객의 새 메시지만 Slack에 알려요.** 상담사 답장, 처음 연결할 때 긁어 온 과거 대화는 저장만 하고 알리지 않아요.
- **외국어는 원문 + 한국어로 보여요.** 한국어 메시지는 번역하지 않아요. 번역이 1분 넘게 안 끝나면 원문만 먼저 알리고, 번역이 끝나면 같은 Slack 메시지를 고쳐 써요.
- **누가 보냈는지 모르면 고객으로 치지 않아요.** "방향 미확인"으로 남겨 두고 Slack 자동 알림에서 빼요. 직원 화면에는 회색 말풍선으로 보여요.
- **사진·파일·음성은 "[사진 첨부]"처럼 종류만 남겨요.** 내용(사진 속 글자, 음성 내용)은 이번 범위가 아니에요.
- **데이터는 Mac mini 안에만 있어요.** 번역 서비스와 Slack으로 보내는 것 외에는 바깥으로 나가지 않아요. 하루에 한 번 백업 사본을 만들어요.
- **화면은 사무실 안에서만 열려요(처음에는).** 공용 비밀번호 하나로 들어가요. 바깥에서 여는 것은 로컬 검증 후 Cloudflare 무료 서비스로 추가해요.
- **왓츠앱 계정 1개 = 고객사 1곳**으로 가정해요. 그 계정에 들어오는 1:1 대화는 전부 저장하고, 빼고 싶은 대화방만 설정에 적어요. 단체 대화방은 처음에는 저장하지 않아요.
- **상담사 휴대폰이 꺼져 있으면 안 돼요.** Mac mini의 왓츠앱은 휴대폰에 연결된 기기라서, 휴대폰을 오래 안 쓰면 연결이 끊겨요.
- 비밀값(번역 서비스 키, Slack 토큰, 공용 비밀번호)은 설정 파일에만 두고 기록에 남기지 않아요.

## 8. 앞으로 할 일 (백로그 요약)
순서대로 진행하고, 각 단계의 확인 기준을 통과해야 다음으로 가요.
1. **화면 읽기 실험(1계정, 대화방 1개):** Mac의 「손쉬운 사용」 기능으로 왓츠앱 화면 글을 빠짐없이 읽을 수 있는지 확인해요. 긴 글, 연속으로 보낸 "네" 두 개, 인용한 옛 메시지, 날짜 구분선이 제대로 읽히는지가 기준이에요. 안 되면 브라우저 왓츠앱(웹 버전)으로 방법을 바꿔요.
2. **저장과 중복 방지:** 읽은 메시지를 Mac mini 안의 보관함에 저장해요. 같은 메시지를 두 번 저장하지 않고, 같은 내용의 다른 메시지는 합치지 않아요. 프로그램을 껐다 켜도 이어서 저장돼요.
3. **한국어 번역:** 외국어 메시지를 GPT로 번역해 원문 옆에 저장해요. 숫자·금액·날짜·이름이 바뀌지 않는지 확인해요.
4. **Slack 알림:** 고객의 새 메시지를 고객사 채널에 원문 + 한국어로 올려요. 다른 고객사 채널로 잘못 가는 일이 없어야 해요.
5. **직원용 대화 화면:** 왼쪽에 고객 목록, 오른쪽에 말풍선 대화. 고객은 왼쪽, 상담사는 오른쪽, 외국어는 아래에 한국어. 새 메시지가 오면 저절로 추가돼요. 답장 칸은 없어요.
6. **안정 운영:** 프로그램이 죽으면 자동으로 다시 켜지고, Mac이 잠들지 않게 하고, 10분마다 운영 Slack 채널에 "살아 있어요" 신호를 보내고, 하루 한 번 백업해요.
7. **여러 계정:** 1계정이 안정되면 계정 10개까지 늘려요. Mac 왓츠앱 앱이 여러 계정을 동시에 지원하는지 먼저 확인해요.
8. (보류) **바깥에서 접속:** Cloudflare 무료 서비스로 직원이 집·휴대폰에서도 화면을 열 수 있게 해요. 회사 Google 계정으로 로그인해요.

### 결정이 필요한 것 (사용자 답변 대기)
- 왓츠앱 계정 하나가 여러 고객사를 담당하는 경우가 있나요?
- 고객사 Slack 채널에 고객사 담당자도 들어와 있나요, 직원만 있나요?
- 고객·고객사·상담사가 섞인 단체 대화방을 실제로 쓰나요?
- 직원 6명 PC가 모두 Mac mini와 같은 사무실 네트워크에 있나요?
- 처음 켤 때 고객별로 과거 대화를 몇 건까지 가져오면 될까요? (기본 200건)

## 9. 용어 풀이
| 용어 | 쉬운 뜻 |
| --- | --- |
| 연결된 기기 | 휴대폰 왓츠앱에 PC나 Mac을 이어서 같은 대화를 보는 기능 |
| 손쉬운 사용(접근성) | Mac이 화면의 글자·버튼을 프로그램이 읽을 수 있게 열어 주는 기능. 원래는 시각장애인용 화면 읽기에 쓰여요 |
| 보관함(DB) | 메시지를 표 형태로 쌓아 두는 저장소. 여기서는 Mac mini 안의 파일 하나예요 |
| 중복 방지 | 같은 메시지를 두 번 저장하지 않는 것 |
| 발송 대기함 | Slack으로 보낼 알림을 먼저 장부에 적어 두고, 하나씩 보내며 "보냄" 도장을 찍는 방식. 프로그램이 중간에 꺼져도 못 보낸 것을 다시 찾을 수 있어요 |
| 실시간 갱신(SSE) | 새 메시지가 오면 화면을 새로고침하지 않아도 저절로 나타나는 방식 |
| heartbeat | 프로그램이 "나 살아 있어요" 하고 주기적으로 보내는 신호. 끊기면 문제가 생긴 거예요 |
| launchd | Mac이 켜지거나 프로그램이 죽었을 때 자동으로 다시 실행해 주는 Mac 기본 기능 |
| Cloudflare Tunnel / Access | 사무실 Mac을 포트 개방 없이 바깥에서 열어 주는 통로와, 그 앞에 붙이는 로그인 문. 둘 다 무료 범위 |
