# 운영 가이드 — 왓츠앱·인스타그램 새 메시지 Slack 알림 (MVP)

> 작성 2026-11-10. 대상: 사무실 Mac mini를 관리하는 사람. 터미널 명령은 그대로 복사해 쓰면 됩니다.

## 1. 무엇을 해 주나요

사무실 Mac mini가 왓츠앱 대화 **목록**과 인스타그램 DM **목록**(Primary·General)만 지켜보다가, 고객의 새 메시지가 오면 고객사 Slack 채널에 알려요. 대화방은 절대 열지 않아서 **안 읽음 뱃지가 그대로 남아요.**

Slack에는 이렇게 와요. 몇 초 사이에 여러 건이 오면 한 메시지로 묶여요.

```
새로운 왓츠앱 알림이 있습니다 · A 상담 계정
• 새로운 알림: 2건
• 확인하지 않은 알림: 4건
> 김민수: 내일 예약 가능할까요?
> +821012345678: 가격 문의드려요
왓츠앱에서 확인해 주세요
```

```
새로운 인스타 DM이 있습니다 · @daclinic_en
• 새로운 알림: 1건
• 확인하지 않은 알림: 3건
> Madalina (Primary): Hi Evan!
인스타그램에서 확인해 주세요
```

### 건수는 이렇게 세요

| | 새로운 알림 | 확인하지 않은 알림 |
| --- | --- | --- |
| 왓츠앱 | 이번에 새로 온 **메시지** 수 | 목록에 보이는 대화들의 안 읽음 **메시지** 합계 (새로 온 것 포함) |
| 인스타그램 | 새로 안 읽음이 된 **대화** 수 | Primary + General에서 안 읽은 **대화** 수 (새로 온 것 포함) |

- 인스타그램은 대화별 메시지 개수를 화면에 보여 주지 않아서 대화 단위로 세요.
- 내용은 목록에 보이는 **마지막 메시지 미리보기**까지만 알려요. 그 앞의 메시지는 앱에서 확인해야 해요.
- 상담사가 보낸 답장, 휴대폰에서 읽어서 뱃지가 사라진 것은 알리지 않아요.
- 프로그램을 처음 켠 순간(인스타그램은 창을 연 뒤 20초까지) 이미 쌓여 있던 안 읽음은 알림 없이 기록만 해요. 그다음 새 메시지부터 "확인하지 않은 알림"에 함께 세요.

## 2. 계정이 막히지 않게 만든 방식

| | 하는 것 | 하지 않는 것 |
| --- | --- | --- |
| 왓츠앱 | 공식 Mac 앱(연결된 기기)이 화면에 띄운 글자를 macOS 「손쉬운 사용」으로 읽기만 함 | 비공식 프로그램·API 사용, 대화방 열기, 클릭, 입력, 메시지 전송. 왓츠앱 서버로 가는 통신이 하나도 늘지 않음 |
| 인스타그램 | 사람이 로그인해 둔 일반 Chrome에서, 이미 화면에 그려진 DM 목록 글자만 읽음 | 인스타그램으로 요청 보내기, 클릭, 스크롤, 새로고침, 비밀번호·쿠키 접근, 비공식 API |

두 서비스 입장에서는 "공식 앱/공식 웹사이트가 켜져 있는 것" 말고 달라지는 게 없어요. 이 두 가지는 자동 시험(`tests/test_whatsapp_watch.py`)으로 계속 확인해요: 왓츠앱 감시기가 클릭·입력을 시도하면 시험이 실패하고, 확장 프로그램 코드에 클릭·요청 코드가 들어가도 실패해요.

**운영하면서 지켜 주세요 (계정 보호):**

- 인스타그램은 **항상 이 Mac mini의 같은 Chrome**에서만 켜 두세요. VPN을 켰다 껐다 하거나 여러 PC에서 번갈아 로그인하면, 이 프로그램과 무관하게 인스타그램이 "의심스러운 로그인"으로 다시 로그인을 요구할 수 있어요.
- 자동 새로고침 확장 프로그램, 자동 답장·자동 팔로우 같은 다른 자동화 도구를 같은 Chrome에 설치하지 마세요.
- 왓츠앱은 **공식 앱만** 쓰세요(App Store / whatsapp.com). 비공식 변형 앱이나 대량 발송 도구는 계정 정지 사유예요.
- 설정에서 왓츠앱 계정을 `mode: collect`로 바꾸지 마세요. 그 방식은 대화방을 열어서 읽음 처리가 돼요(전체 대화 저장용, 이번 MVP에서는 안 써요).

## 3. 처음 설치 (한 번만)

### 3-0. 새 Mac에 먼저 깔아 둘 것
이 프로그램은 **Apple 칩(M1 이후) Mac, macOS 13 이상**에서 돌아요. 터미널(응용 프로그램 → 유틸리티 → 터미널)에서 차례로 실행해요.

```sh
xcode-select --install                               # 앱을 만드는 도구(Swift). 창이 뜨면 "설치"
curl -LsSf https://astral.sh/uv/install.sh | sh      # Python 실행 도구(uv). 설치 후 터미널을 새로 열기
```

- 이 저장소 폴더를 새 Mac으로 복사해요. **`문서`·`데스크탑`·`다운로드` 폴더 밖**(예: `~/apps/sns_notify`)에 두세요. 안에 두면 macOS가 폴더 접근 허용을 한 번 더 물어요.
- `config.yaml`, `.env`, `data/`는 복사되지 않는 파일이에요(비밀값·기록). 새 Mac에서 3-2대로 새로 만들어요.
- **Mac의 언어는 한국어로 두세요.** 왓츠앱 화면 문구("메시지, …님께 받았습니다")를 한국어 기준으로 읽어요. 영어 화면이면 새 메시지를 알아보지 못해요.
- Chrome, 공식 WhatsApp 앱(App Store), Slack(확인용)을 설치해요.

### 3-1. Slack 준비
1. https://api.slack.com/apps → Create New App → 권한(Bot Token Scopes)에 `chat:write` 추가 → 워크스페이스에 설치.
2. `xoxb-`로 시작하는 Bot Token을 복사해 `.env`의 `SLACK_TOKEN_MAIN=`에 넣어요.
3. 알림을 받을 채널에서 `/invite @봇이름`. 채널 ID(채널 이름 우클릭 → 링크 복사, 마지막 `C…` 부분)를 `config.yaml`에 넣어요.
4. (권장) 운영 전용 채널을 하나 더 만들어 `ops.slack_channel_id`에 넣어요. 10분마다 "살아 있음" 신호와 문제 알림이 여기로 와요.

### 3-2. 설정 파일
```sh
cp config.example.yaml config.yaml
cp .env.example .env && chmod 600 .env
```
`config.yaml`에서 고칠 곳:
```yaml
clients:
  - key: clinic-a
    name: A 클리닉
    slack_channel_id: C11111111        # 이 고객사 알림 채널
    slack_token_ref: SLACK_TOKEN_MAIN
    accounts:
      - key: clinic-a-wa1
        label: A 상담 계정              # Slack 제목에 나오는 이름
        exclude: []                    # 알림에서 뺄 대화방 이름
instagram:
  - account: daclinic_en               # 인스타그램 아이디(@ 없이)
    client: clinic-a                   # 어느 고객사 채널로 보낼지
```
`.env`에는 `SLACK_TOKEN_MAIN`, `VIEWER_PASSWORD`, `SESSION_SECRET`, `INGEST_TOKEN`(16자 이상 아무 값)을 채워요. `OPENAI_API_KEY`는 비워 둬도 돼요(번역은 이번 MVP에서 안 써요).

### 3-3. 왓츠앱 + 「손쉬운 사용」 권한
「손쉬운 사용」은 Mac이 화면의 글자·버튼 정보를 프로그램에게 읽게 해 주는 권한이에요. 이 권한이 없으면 왓츠앱 목록을 읽지 못해요. **「WhatsApp 수집기」 앱 하나에만** 주면 되고, 터미널이나 Python에는 줄 필요가 없어요.

1. 공식 WhatsApp 앱을 열고, 상담 휴대폰의 왓츠앱 → 설정 → 연결된 기기 → 기기 연결로 QR을 찍어요. 대화 목록이 보이면 돼요.
2. 터미널에서 저장소 폴더로 이동해 설치해요.
   ```sh
   cd ~/apps/sns_notify
   uv sync
   scripts/install_app.sh
   ```
   메뉴 막대(화면 오른쪽 위)에 말풍선 아이콘이 생기고, "손쉬운 사용 접근 권한" 안내 창이 한 번 떠요. **"시스템 설정 열기"**를 누르세요. (창을 놓쳤으면 말풍선 아이콘 → "손쉬운 사용 설정 열기")
3. 권한 켜기:
   - 시스템 설정 → **개인정보 보호 및 보안 → 손쉬운 사용**
   - 목록에서 **「WhatsApp 수집기」** 옆 스위치를 켜요. Mac 암호나 Touch ID를 물으면 입력해요.
   - 목록에 없으면 아래 **+** 버튼 → `Command+Shift+G` → `~/Applications` 입력 → `WhatsAppCollector` 선택 → 열기.
4. 확인: 말풍선 아이콘을 눌렀을 때 **"손쉬운 사용 권한: 허용됨"**이라고 나오면 끝이에요. "필요"로 남아 있으면 아이콘 → "수집기 다시 시작"을 한 번 눌러요.
5. WhatsApp 창은 **대화 목록("모두" 탭)이 보이는 상태로 열어 두고, 최소화하지 마세요.** 창을 세로로 길게 두면 더 많은 대화가 세어져요(화면에 보이는 대화만 읽을 수 있어요).

**권한을 다시 켜야 하는 경우**
- `scripts/install_app.sh`를 다시 실행했는데 "앱이 새로 설치/갱신되어 이전 허용은 초기화되었습니다"라고 나올 때(앱 자체가 바뀐 경우). 알림 규칙(Python 코드)만 고친 경우에는 그대로 유지돼요.
- 스위치가 켜져 있는데도 "필요"로 나올 때: 목록에서 「WhatsApp 수집기」를 선택해 **−** 로 지우고, 3번을 다시 해요.
- 권한이 꺼지면 운영 채널에 `ax_permission_missing` 알림이 와요.

### 3-4. 인스타그램
1. Mac mini의 Chrome에서 인스타그램에 로그인해요.
2. `chrome://extensions` → 개발자 모드 켜기 → "압축해제된 확장 프로그램을 로드" → 이 저장소의 `chrome-extension` 폴더 선택.
3. 확장 프로그램의 "세부정보 → 확장 프로그램 옵션"에 주소 `http://localhost:8787`, 토큰에 `.env`의 `INGEST_TOKEN` 값을 넣고 저장.
4. **Chrome 창을 2개** 열어요. 창 1: `instagram.com/direct/inbox/` (Primary). 창 2: 같은 주소에서 **General** 탭 선택. 두 창 모두 최소화하지 말고 그대로 둬요(다른 창 뒤에 가려지는 것은 괜찮아요).
5. Chrome 설정 → 성능 → **메모리 절약 모드 끄기**(또는 "항상 활성 상태로 유지할 사이트"에 `instagram.com` 추가). 켜져 있으면 Chrome이 탭을 재워서 감시가 멈춰요.
6. 확장 프로그램 아이콘을 누르면 계정·탭별로 "수집기 전송 성공"이 보여야 해요.

### 3-5. Mac mini 설정
- 시스템 설정 → 잠금 화면: 화면 보호기·화면 끄기·"암호 요구"를 **안 함**으로. 화면이 잠기면 왓츠앱 감시가 멈춰요(운영 채널에 "화면 잠김" 알림이 와요).
- 사용자 및 그룹 → 자동 로그인 켜기(정전·재부팅 후 자동 복구). 재부팅 후 WhatsApp과 Chrome(인스타그램 창 2개)이 다시 열렸는지 확인하세요. 두 앱을 "로그인 항목"에 추가하고, Chrome은 "이전에 열었던 페이지 계속 보기"로 설정해 두면 편해요.
- 잠자기 방지는 「WhatsApp 수집기」 앱이 알아서 해요.

### 3-6. 첫날 확인 (꼭 해 주세요)
다른 휴대폰에서 상담 계정으로 테스트 메시지를 보내며 확인해요.

1. **왓츠앱으로 메시지 2개 보내기** → Slack에 "새로운 왓츠앱 알림이 있습니다"가 오는지, Mac과 휴대폰 왓츠앱에 **안 읽음 뱃지가 남아 있는지**.
2. 터미널에서 `uv run python -m app.cli watch` 실행:
   - `계정 안 읽음 2`처럼 숫자가 나오면 뱃지 숫자까지 읽히는 거예요. 이후 Slack에 "확인하지 않은 알림" 줄이 같이 와요.
   - `뱃지 미확인`이라고 나오면, 이 왓츠앱 버전은 뱃지 숫자를 다른 문구로 알려 주는 거예요. **알림 자체는 정상으로 오고**, "새로운 알림 N건"까지만 표시돼요. 이때는 메뉴 막대 아이콘 → 「화면 구조 기록 (진단)」을 누르고 개발자에게 알려 주세요(문구 한 줄만 추가하면 돼요).
3. **인스타그램 DM 보내기**(Primary 1건, General에 있는 계정으로 1건) → Slack에 "새로운 인스타 DM이 있습니다"가 오는지, 인스타그램에서 안 읽음(굵은 글씨·파란 점)이 남아 있는지.
4. Mac mini를 재부팅해서 다시 알림이 오는지.

## 4. 평소 운영

**켜져 있어야 하는 것 (하나라도 꺼지면 그 채널 알림이 멈춰요)**

| 항목 | 확인 방법 |
| --- | --- |
| Mac mini 전원·로그인·화면 잠금 해제 상태 | 운영 채널의 10분 신호 |
| 「WhatsApp 수집기」 (메뉴 막대 말풍선) | 아이콘 메뉴의 상태 줄 |
| WhatsApp 앱 창 (대화 목록 보임) | 운영 신호에 "연결됨" |
| Chrome 인스타그램 창 2개 (Primary, General) | 운영 신호의 "Instagram … 마지막 확인 N초 전" |
| 상담 휴대폰 (인터넷 연결) | 14일 넘게 꺼져 있으면 Mac 왓츠앱 연결이 풀려요 |

**하지 말아야 하는 것**

- **Mac mini에서 왓츠앱 대화방이나 인스타그램 대화를 눌러 열지 마세요.** 열면 읽음 처리되고 뱃지가 사라져요. 확인·답장은 지금처럼 휴대폰(또는 각자 PC)에서 해요.
- 감시용 인스타그램 창에서 탭(Primary/General)을 바꾸거나 스크롤하지 마세요. 오래된 안 읽은 대화가 화면에 새로 들어오면 새 알림으로 잘못 갈 수 있어요(인스타그램 목록에는 정확한 시각이 없어서 구분하지 못해요).
- 왓츠앱 목록에서 검색창이나 "읽지 않음" 필터를 켜 둔 채로 두지 마세요("모두"로 둬요).

**알림을 받은 뒤**

- 휴대폰에서 대화를 읽으면 Mac과 인스타그램 웹의 뱃지도 같이 줄어요. 다음 알림의 "확인하지 않은 알림" 숫자에 자동으로 반영돼요.
- 읽지 않고 두면 다음 알림에서 계속 "확인하지 않은 알림"에 포함돼요.

## 5. 상태 확인과 문제 해결

```sh
uv run python -m app.cli watch     # 목록별 마지막 확인 시각, 안 읽은 대화, 최근 알림과 Slack 전송 결과
uv run python -m app.cli events    # 운영 이벤트(권한 해제, 화면 잠김, 전송 실패 등)
uv run python -m app.cli status    # 전체 상태(JSON)
```

| 증상 | 원인과 조치 |
| --- | --- |
| 운영 채널 10분 신호가 끊김 | Mac mini가 꺼졌거나 수집기가 멈춤. Mac을 확인하고 메뉴 막대 아이콘 → "수집기 다시 시작" |

## 6. 알고 있는 한계

- **화면에 보이는 대화만 세요.** 왓츠앱 목록에서 화면 아래로 밀려난 오래된 안 읽은 대화는 "확인하지 않은 알림" 합계에서 빠져요(새 메시지가 오면 맨 위로 올라와서 다시 세어져요). 인스타그램도 목록에 로드된 대화까지예요.
- **Mac 왓츠앱에서 열려 있는 대화방**에 온 메시지는 왓츠앱이 스스로 읽음 처리할 수 있어요. 알림은 가지만 뱃지는 안 생길 수 있으니, Mac mini에서는 대화방을 열어 두지 마세요.
- 같은 고객이 같은 분에 똑같은 글을 다시 보내면, 뱃지 숫자를 읽을 수 있을 때만 새 알림으로 잡혀요.
- 사진·음성·스티커는 미리보기 문구가 왓츠앱이 알려 주는 그대로 나와요(실기기 샘플로 아직 다듬지 않았어요).
- 목록에 마지막 메시지 대신 "입력 중…"이나 작성 중인 초안이 보이는 동안은 새 메시지로 치지 않아요(잘못된 알림 방지). 그 표시가 사라지면 바로 정상으로 돌아와요.
- 처음 보는 대화는 마지막 메시지 시각이 최근일 때만 알려요. 창을 키우거나 스크롤해서 예전 대화가 화면에 들어오는 것은 알리지 않아요.
- 인스타그램 "요청(Requests)" 폴더는 알리지 않아요.
- 다음은 실제 계정으로 아직 확인하지 못했어요. 3-6에서 확인해 주세요: ① 왓츠앱 안 읽음 뱃지 숫자가 읽히는지 ② Slack 실제 전송(토큰 미설정 상태에서 개발) ③ Chrome 창이 가려진 상태로 오래 둘 때 인스타그램 목록이 계속 갱신되는지 ④ 화면 잠금 상태 동작.
