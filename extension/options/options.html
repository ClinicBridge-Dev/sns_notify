수신함 열기

운영 안내

감지가 끊기지 않게 하는 방법과 여러 사람이 쓸 때의 주의 사항입니다.

자세히
  • 수신함 탭을 닫지 않습니다. 상담하던 탭에서 광고 관리 등 수신함 밖으로 이동하면 감지가 멈춥니다. 다른 화면은 새 탭에서 엽니다.
  • 두 채널 모두 발신자와 미리보기를 받고 싶으면 Instagram 탭과 WhatsApp 탭을 하나씩 열어 둡니다.
  • 브라우저의 탭 절전(메모리 절약) 대상에서 business.facebook.com을 제외합니다.
  • 여러 사람이 각자 설치하면 같은 알림이 사람 수만큼 게시됩니다. 알림 담당 브라우저 1대에서만 "Slack 알림 사용"을 켜고, 나머지 브라우저에서는 끄세요(끄면 오류로 표시되지 않습니다).

요금제
무료 DeepL 키(:fx)입니다. 상담 내용이 의료 정보에 해당하면 DeepL 전송은 처리 위탁·국외 이전 검토 대상일 수 있습니다. 텍스트를 저장하지 않고 학습에 쓰지 않는다고 명시한 유료 API 요금제를 권장합니다.

      적용 방식

      도움말

      자주 생기는 문제

      먼저 아래 세 가지를 확인하세요.

      번역과 Slack이 모두 안 될 때

      확장 프로그램의 사이트 액세스 권한이 꺼져 있을 수 있습니다. 시작하기 메뉴의 1단계에서 네 곳이 모두 "허용"인지 확인하세요.

      "감지가 중단되었습니다" 알림이 왔을 때

      수신함 탭이 열려 있는지 확인하고 새로고침하세요. 확장 프로그램을 수정하거나 다시 로드한 뒤에는 수신함 탭도 새로고침해야 합니다.

      한글이 번역되지 않고 전송될 때

      입력창 위 번역 스위치가 켜져 있는지 확인하세요. 번역 메뉴의 "한글 입력을 번역해 전송"도 켜져 있어야 합니다.

      알려진 한계

      이 확장 프로그램은 수신함 화면에 보이는 것만으로 동작합니다.

      • 이 확장 프로그램은 Meta가 승인한 연동 방식이 아닙니다. 계정 제한 위험이 없다고 보장할 수 없습니다.
      • Slack 알림은 탭이 열려 있고 화면이 갱신되는 동안에만 동작합니다. 모든 메시지를 한 건씩 보장하지 않으며, 연속 메시지는 1건으로 합쳐질 수 있습니다.
      • 브라우저가 완전히 꺼지면 감지가 중단되어도 경고를 보낼 수 없습니다.
      • Meta가 화면 구조를 바꾸면 동작이 멈출 수 있습니다.
      • 번역 품질은 DeepL에 달려 있습니다. 한글 입력 번역은 확인 단계 없이 전송되므로 오역이 고객에게 그대로 전달될 수 있습니다.
      • 상담 내용이 DeepL로 전송됩니다. 텍스트를 저장하지 않고 학습에 쓰지 않는다고 명시한 DeepL 유료 API 요금제를 권장합니다.
      • Slack Webhook 주소와 DeepL 키는 확장 프로그램 저장소에 평문으로 저장됩니다. 확장 프로그램과 브라우저 프로필을 다른 사람과 공유하지 않습니다.
      • 채널 탭 전환, 검색, 필터 직후 몇 초 동안 온 메시지는 발신자와 미리보기 없이 미확인 대화 수만 담긴 알림으로 옵니다.
      • 같은 고객이 이어서 보낸 메시지는, 그 대화를 읽기 전까지 알림이 다시 오지 않을 수 있습니다.
      • 상담원이 대화를 "읽지 않음으로 표시"하면 새 메시지 알림이 나갈 수 있습니다.
      • 한글 조합 처리는 운영체제와 입력기에 따라 다르게 동작할 수 있습니다. 검증한 환경에서만 사용합니다.
